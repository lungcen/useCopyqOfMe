# CopyQ 剪贴板管理配置

> 基于 CopyQ 的剪贴板增强配置，实现分类管理、快捷操作、自动归档。

## 简介

本仓库包含 CopyQ 剪贴板管理工具的配置文件和安装包。通过自定义命令和快捷键，实现剪贴板内容的分类存储和快速调用，提升日常工作效率。

## 文件说明

| 文件 | 说明 |
|------|------|
| `copyq-17.0.0-setup.exe` | CopyQ v17 安装包 |
| `copyq配置文件.cpq` | 个人配置文件，包含自定义命令和快捷键 |
| `CopyQ-master/` | CopyQ 源码 |

## 安装方式

1. 运行 `copyq-17.0.0-setup.exe` 安装 CopyQ
2. 打开 CopyQ，点击菜单栏 **文件** → **导入**
3. 选择 `copyq配置文件.cpq` 导入配置
4. 重启 CopyQ 使配置生效

## 快捷键配置

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Shift + V` | 打开 CopyQ 面板 |
| `Ctrl + \`` | 将当前剪贴板内容保存到「重要信息」标签页 |
| `Alt + 1` | 复制「重要信息」标签页第 1 条内容到剪贴板 |
| `Alt + 2` | 复制「重要信息」标签页第 2 条内容到剪贴板 |
| `Alt + 3` | 复制「默认」标签页第 2 条内容到剪贴板 |

## 标签页说明

| 标签页 | 用途 |
|--------|------|
| 默认 | 常规剪贴板历史记录 |
| 重要信息 | 手动保存的重要数据 |
| 图片信息 | 自动归档 QQ、微信等软件的截图 |

## 自动规则

- QQ / 微信等软件的截图会自动归类到「图片信息」标签页，无需手动操作
